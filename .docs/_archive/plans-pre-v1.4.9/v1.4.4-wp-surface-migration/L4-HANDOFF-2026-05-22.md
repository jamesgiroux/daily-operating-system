## What renders against real substrate (NOT mock)

**Nothing usable yet.** Bring-a-trailer account page renders "Account identity unavailable" because `get_entity_intelligence` producer fails at `ProvenanceBuilder::finalize()` (DOS-764). Per the sibling-session diagnosis: producer is registered + invoked + builds the envelope correctly, but only attributes `attributes` and `schemaVersion` while the envelope has many other leaves (`subject`, `sections`, `facts`, `recordEntries`, etc) that need attribution. Finalize rejects → producer error returns as `AbilityInvokeError::Ability` → bridge maps to `AbilityUnavailable` → wire code `ability_not_registered` (HTTP 404).

The DOS-762 observability split shipped the `ProducerUnavailable` variant but the bridge-side `surface_error()` mapper wasn't updated to route producer errors there — that's part of DOS-764's wire-up.
