## §1 — Why W0 exists

v1.5.0 builds the Tauri React renderer over the **already-built** ADR-0130 Composition substrate (block model + BlockType registry + §3.1 fallback). Before that renderer consumes the substrate, two risks must be closed and one status settled:

1. The reverted WP-primary work (ADR-0135) is still in the tree. It must be **banked** (preserved, out of the active build path) — not deleted (future headless-WP state), not extended (no WP energy now). And the cleanup must **not** remove the composition orchestrator + local-loopback route, which are shared substrate the Tauri renderer reuses.
2. The substrate (envelope + producer + orchestrator) was built while WP was the primary surface. Confirm it carries no WordPress-shape assumptions before the Tauri renderer inherits the contract.
3. ADR-0130 + ADR-0122 are still `Proposed`. v1.5.0 is ADR-0130's first real implementation; accept it (and 0122, precisely as Option A) so the version builds on accepted contracts.
