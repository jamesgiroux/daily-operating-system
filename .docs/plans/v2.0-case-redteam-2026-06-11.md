## Convergent findings (both reviewers independently)

1. **Latency causality unproven; decision was unfalsifiable mid-flight.** The 8.8 s was measured 2026-05-27 on the legacy `get_account_detail` path (the live composition-backed account page no longer calls it — verified) and pre-DOS-866. Cheap-fix inventory: DOS-866 phased persist ships regardless; bounded paged trust recompute already exists (`trust_recompute.rs:65`) with exactly 2 unbounded call sites remaining (`intel_queue.rs:3583`, `invalidation_jobs.rs:449`); commit-on-page-load is 60 s-cache miss-path behavior (`composition_render_orchestrator.rs:52`), removable in isolation; the unbounded depth-3 read takes a `LIMIT`. The repo's own throughput plan already gated read-model work behind re-measurement. → **Amendment: mandatory post-fix re-measurement checkpoint + numeric target + kill criteria for the read-model commitment.**
2. **Framework adoption worse than the disease.** Codex verified against LiveStore's own docs: **no native Tauri adapter exists** (web adapter in Tauri only; docs WIP) — correcting the research input that fed the original gate decision. Event-sourcing frameworks solve multi-device sync, a problem this single-user single-device product doesn't have; TanStack DB is a JS client layer across the Rust trust boundary. → **Amendment: default flips to owned Rust materialized projections + reactive subscription behind existing service contracts; a framework must beat that at the L0.**
3. **Second-system risk underpriced.** Data-layer workstream had zero weeks assigned; chat hatch unpriced; design phase untimeboxed; repo's own record (3 DOS-852 retrofit failures, W5 parity spiral, two generations left in-tree) suggests 2.5–3× the 10–15-week headline. → **Amendment: per-workstream pricing, timeboxed design phase, headline restated as surface-conversion-only.**
4. **The product case survives unanimously.** Briefing-first taxonomy, blocks-only rendering, deletion-as-AC, dual-system kill — approved on internal grounds (audit's 21-of-25 hand-wired vs. thesis). The greenfield section is demoted from "independent derivation" to "landscape scan consistent with the direction"; unsourced trend figures struck.
