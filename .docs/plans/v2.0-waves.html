Operating rules

The whole control surface, restated once.

Two gates, no covenants

Gate 1 (latency checkpoint) and Gate 2 (instrumentation readout) are the only program-level gates — the over-hardening correction stands. Everything else is the normal ladder: per-ticket L0, L2 before merge, L4 on user-facing conversions.

Deletion is the acceptance criterion

A conversion is done when its predecessor is deleted — the measured precedent (two generations left in-tree, 27 orphans) is the named failure mode. Per-surface rollback: the old route stays addressable until the new surface survives daily use.

Substrate changes run their own L0s

Any wave item touching claim semantics, the writer queue, the abilities contract, or the composition model beyond consuming them exits the wave and runs as substrate work (ADR-0139 sequencing rule).
