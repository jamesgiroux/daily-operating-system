## W0 close gate items (must ship in v1.4.5 W0 before W1-A starts)

### 1. ADR-0107 amendment — add `WorkspaceFile` DataSource variant

**Status:** ⛔ NOT YET on dev. The current `DataSource` enum at `src-tauri/abilities-runtime/src/abilities/provenance/source.rs:73` has variants: `User`, `Google`, `Glean`, `Clay`, `Ai`, `CoAttendance`, `LocalEnrichment`, `Other`, `LegacyUnattributed`. No `WorkspaceFile`.

**Required:** new ADR amendment at `.docs/decisions/0107-source-taxonomy-alignment.md` adding:

```rust
DataSource::WorkspaceFile { kind: WorkspaceFileKind }
```

Per ADR-0107 §1 addition rules, new sources require an ADR amendment (not the `Other(SourceName)` path).

**Cascade:** all `match DataSource` sites in `freshness_decay.rs`, `scoring_class`, `is_structured_trusted_source`, etc. need a new arm. Estimate: ~6-10 sites across `abilities-runtime/` and `src/db/data_lifecycle.rs`.

**Also requires:** DB-level enum at `src-tauri/src/db/data_lifecycle.rs:315` mirrored. (Two `DataSource` enums currently exist; W0 should reconcile or document the duality.)
