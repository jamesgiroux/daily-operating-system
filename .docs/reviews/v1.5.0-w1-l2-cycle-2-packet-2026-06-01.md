## Required Regression Checks

1. **Shared projection service:** `get_projected_composition`, `/v1/local/project-composition`, and signed surface projection route must delegate render/cache/project/store behavior through `project_composition_for_surface(...)`; authorization remains at each boundary before delegation.
2. **Versionless miss guard:** cache lookup may use the current DB composition version, but the miss singleflight key must not use caller/request `composition_version`.
3. **Provenance rendering:** block provenance refs must resolve against `rendered_provenance.value.field_attributions` or `about_this.details.field_attributions`, and renderer output must not expose raw field paths, dropped payloads, source text, or diagnostics.
4. **Renderer exhaustiveness:** React renderer coverage must be anchored to Rust `BlockType::type_id()` so new canonical Rust block types fail frontend tests until rendered or intentionally mapped.
5. **Section indexes after fallback drops:** `ProjectedSection.block_indexes` must index the compact projected `blocks` array after dropped unknown blocks; `ProjectedBlock.block_index` may retain the original composition/audit position.
6. **Account navigation races:** changing Account route identity must clear prior account data while loading and must ignore stale late responses from older requests; same-account refetch may preserve current data.
7. **Mixed evidence:** sections with both claim projections and Account snapshot fields must render both claim blocks and snapshot evidence blocks.
8. **Fallback DOM privacy:** runtime renderers must not write raw `block_id` or `original_type_id` into DOM attributes for fallback/custom blocks.
9. **W1-F live proof:** proof must show seeded generic account data -> real Tauri `invoke("get_projected_composition")` -> producer invocation -> projected sections drive folio nav -> React blocks render trust/provenance/fallback -> finite ending -> desktop and mobile screenshots.
